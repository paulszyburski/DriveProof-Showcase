# DriveProof

DriveProof helps rental-car customers create a clear record of a vehicle's
condition at pickup and return. It keeps inspection photos, rental details, and
supporting documents together, then turns the evidence into a shareable PDF.

## What it does

- Creates organized rental records without requiring an account
- Guides users through pickup and return inspections
- Captures damage and condition photos
- Keeps rental documents with the relevant vehicle record
- Compares pickup and return evidence
- Saves evidence photos and exports PDF reports
- Stores rental records locally on the device
